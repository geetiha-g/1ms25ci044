# Champion-Challenger Model Comparison

## 1. Task and Models

Task: Sentiment Classification

Model A - Initial Champion:
distilbert-base-uncased-finetuned-sst-2-english

Model B - Challenger:
siebert/sentiment-roberta-large-english

Dataset: Custom sentiment evaluation dataset.

Labels:
1 = Positive
0 = Negative

## 2. How to Run

1. Install requirements.
2. Start the MLflow tracking server.
3. Run evaluate.py.
4. Run register_champion.py.
5. Run predict_from_mlflow.py.

## 3. Champion Decision Rule

Primary metric: Macro F1-score (higher is better).

The Challenger must improve the macro F1-score
by at least 0.01 to replace the Champion.

If the improvement is less than 0.01,
the faster model remains Champion.

The Challenger will also be rejected if its
average inference time exceeds 5 times that
of the current Champion.

## 4. Results

Both models achieved an accuracy of 1.00 and a macro-F1 score of 1.00 on the 20-example evaluation dataset.

| Metric | DistilBERT (Champion) | RoBERTa (Challenger) |
|---|---:|---:|
| Accuracy | 1.00 | 1.00 |
| Macro F1 | 1.00 | 1.00 |
| Average Latency (ms) | 23.15 | 190.40 |
|Total Inference Time (s)|	0.463|	3.808

Since both models achieved identical accuracy and macro-F1 scores, DistilBERT was selected as the Champion because it had significantly lower average prediction latency.

The evaluation dataset contains only 20 examples, so these results should not be considered a guarantee of performance on larger or unseen datasets.

## 6. Discussion

The experiment compared DistilBERT and RoBERTa for sentiment classification using the same evaluation dataset of 20 text examples. Both models achieved an accuracy of 1.00 and a macro-F1 score of 1.00, correctly classifying all 20 examples in the evaluation set.

Since both models achieved identical predictive performance, the predefined Champion–Challenger decision rule favoured the faster model. DistilBERT recorded an average inference latency of 23.15 ms and a total inference time of 0.463 seconds, whereas RoBERTa recorded an average latency of 190.40 ms and a total inference time of 3.808 seconds.

RoBERTa's average inference latency was approximately 8.22 times higher than DistilBERT's, exceeding the predefined 5× latency limit. Therefore, DistilBERT was retained as the Champion, while RoBERTa remained the Challenger.

MLflow was used to track experiments, log evaluation metrics and artifacts, register both models, and assign Champion and Challenger aliases. The predictions on five new examples were also generated by loading the Champion through its MLflow alias.

However, the evaluation dataset contained only 20 examples, which limits the generalisability of the results. A larger and more diverse dataset would be needed to evaluate performance on complex language, sarcasm, negation, and different writing styles more reliably.
## 7. Model Disagreement Analysis

Both models produced identical predictions across all
20 examples in the original evaluation dataset.
Therefore, no disagreements were found in the original
evaluation set.

For additional qualitative analysis, a separate
supplemental set of 30 examples was tested. Five
representative disagreement examples were selected
and documented in `outputs/disagreement_examples.csv`.

These examples demonstrate differences in how the
models interpret mixed sentiment, negation and
sarcastic wording. The supplemental examples were
used only for qualitative analysis and were not
included in the original evaluation metrics.
